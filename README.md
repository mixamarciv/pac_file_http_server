Минималистичный http сервер на Rust, раздает содержимое указанного pac файла на указанном порту.
Читает файл при каждом обращении (чтобы вы могли менять его на лету без перезапуска сервера) и отдает его с правильными заголовками для Chrome.
Для сборки не требует внешних зависимостей, использует только стандартную библиотеку std.

пример запуска:

```bat
pac_file_http_server 127.0.0.1:6001 c:/path/to/script.pac
```

далее этот хост можно использовать в хром:

```bat
chrome --proxy-pac-url="http://127.0.0.1:6001/proxy1.pac"
```
